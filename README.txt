Dataset Title:
Dragon Fruit Leaf Disease Image Dataset

Description:
This dataset contains real-world images of dragon fruit plant stems and leaves collected from agricultural farms. 
The images are categorized into five classes representing healthy and diseased plants.

Classes:
1. Anthracnose
2. BrownSpot_Early
3. Healthy
4. StemCanker
5. Stress
